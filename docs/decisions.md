# 확정 결정 목록

> 2026-11-09 그릴링 세션에서 확정. 결정을 바꾸려면 코드보다 이 문서를 먼저 고치고, 사용자 승인을 받는다.
> 형식: **결정** — 이유
> 서비스별 세부 정책은 `docs/features/`에 있다. 이 문서와 세부 정책이 다르면 **세부 정책(더 최근)이 우선**한다. 범위 밖 기능은 `docs/backlog.md`.

## 1. 브랜드
- **FLUTCH(플러치)**, 슬로건 "Feel the Moment. Live on FLUTCH." — FLUTTER(두근거림) + CLUTCH(짜릿함).
- 기능 구성은 치지직·숲과 비슷하게, **화면 디자인과 브랜딩은 FLUTCH 고유**로 만든다.
- 화폐 단위 **비트(beat), 1비트 = 1원**.

## 2. 기술 스택
| 영역 | 결정 | 이유 |
|---|---|---|
| 백엔드 | **Rust · Axum · SQLx · PostgreSQL** | Rust 프로젝트 경험이 목적. 컴파일러가 AI 생성 코드의 실수를 실행 전에 걸러준다 |
| 프론트 | **React · Vite · TypeScript · Tailwind** | LiveKit 공식 React 컴포넌트, Stitch(Tailwind) 시안 이식 용이 |
| 스트리밍 | **LiveKit Cloud로 시작**, 필요 시 Oracle 서버에 직접 설치로 이전 | 첫 2~3일 안에 송출→시청을 확실히 통과. 이전 시 URL·키만 바뀐다 |
| 결제 | **토스페이먼츠 테스트 모드** | 테스트가 편하고 사업자 없이 테스트 키 사용 가능 |
| DB 마이그레이션 | **SQLx migrate** (Flyway 미사용) | Rust 단일 서비스에 Java 도구 불필요. 쿼리 컴파일 검증과 같은 도구 |
| Redis | **사용하지 않음** | 백엔드 1대. 세션=Postgres, 채팅 전달=`tokio::broadcast`, 시청자 수=LiveKit, rate limit=메모리. 채팅 전달부는 인터페이스로 분리해 나중에 Redis pub/sub로 교체 가능 |
| BFF | **별도 BFF 서버 없음** | 클라이언트 1종, 백엔드 1개. httpOnly 세션 쿠키로 BFF의 보안 이점은 이미 확보 |
| API | **RESTful, `/api/v1` 접두사** + 실시간 이벤트는 **WebSocket 하나** | 리소스는 경로, 필터는 쿼리, 데이터는 본문 |

## 3. 인프라·배포
- **Oracle Cloud ARM 무료 티어 새 인스턴스(3 OCPU / 18GB)**. 부족하면 포트폴리오 인스턴스를 내리고 4 OCPU / 24GB 전체 사용.
- 도메인 **`flutch.kro.kr`** (내도메인), **nginx + certbot**으로 HTTPS. 화면 공유·카메라는 HTTPS 필수.
- **Docker Compose**로 백엔드·DB·모니터링 실행. **GitHub Actions에서 ARM 이미지 빌드 → GHCR → SSH 배포** (서버에서 Rust 빌드하지 않음).
- OCI Security List와 서버 iptables 둘 다 포트를 연다.
- 모니터링: **Prometheus + Loki + Grafana**, 로그 수집은 **Grafana Alloy**(Promtail 지원 종료 예정). `/metrics`는 외부 비공개, Grafana는 로그인 필수.
- 운영 기본값: CSRF(`SameSite=Lax` + 변경 요청 `Origin` 검사), `tracing` 구조화 로그 + 요청 ID, `GET /api/v1/health`, 매일 `pg_dump` → Oracle Object Storage 7일 보관, 비밀값은 GitHub Secrets.

## 4. 인증·계정
- **아이디(4~20자 영문 소문자·숫자) + 비밀번호(8~64자, 영문+숫자) + 닉네임**. 이메일·휴대폰 인증 없음. **카카오 로그인은 녹화 단계 다음에 추가**(입구만 추가, 세션·인가 구조 동일).
- **argon2** 해시, **서버 세션(Postgres) + httpOnly 쿠키**. 로그아웃 시 서버에서 즉시 무효화. 로그인 시도 횟수 제한.
- 닉네임 **중복 불가**, 변경 후 **30일 재변경 불가**(`nickname_changed_at`, 가입 시 설정은 제외). 비밀번호 변경 지원. **간단한 회원 탈퇴 지원**(잔액은 경고 후 소멸 기록, 원장·채팅 보존).
- 프로필 사진 업로드 없음. 기본 프로필은 **마스코트 고양이 얼굴 + 배경색 6종**(사용자 id로 고정).
- 테스트 계정: 시드 계정(스트리머1, 스트리머2, 시청자) + **로그인 화면 "테스트 계정으로 바로 로그인" 버튼**. 시드 비밀번호는 운영에서 환경변수.

## 5. 방송
- **방송 등록 → 송출 → 종료** 모델. 채널 개념은 스트리머 페이지로만 표현. **사용자당 동시 LIVE 1개**.
- 상태: **READY → LIVE → ENDED**. **ENDED는 최종**(다시보기와 1:1). 새 방송은 새로 등록, "이전 방송 정보 복사" 제공.
- 방송 중 **제목·카테고리 변경 허용**, 시청자 화면·목록에 실시간 반영.
- 방송 중 삭제 → 서버가 **송출 강제 종료 후 삭제**.
- 비정상 종료: LiveKit 웹훅으로 송출자 퇴장 감지, **60초 유예** 후 자동 ENDED. 유예 중 시청자에게 "재연결 대기" 표시. 서버 시작 시 LiveKit 실제 방 상태와 DB 동기화.
- 송출 권한: 서버가 **로그인한 소유자에게만 publish 토큰** 발급, 시청자는 subscribe 전용 토큰. 종료 시 서버가 방을 닫아 송출을 실제로 끊는다.
- REST 표현: `POST /api/v1/broadcasts/{id}/live`(송출 시작), `DELETE /api/v1/broadcasts/{id}/live`(종료).

### 송출 화면
- PC: 화면 공유 + 마이크 + 음소거 + 화면 소스 변경 + 마이크/화면 소리 볼륨 슬라이더. 탭/시스템 소리는 `getDisplayMedia` 오디오. **PC 웹캠 모드 지원**. **화면+웹캠 동시(PIP)는 트랙을 따로 보내고 시청자 화면에서 겹치는 방식**(브라우저 캔버스 합성 금지 — 백그라운드 탭에서 멈춤), 필수 완료 후 T09b.
- 모바일: 전/후면 카메라 전환, 음소거, Wake Lock.
- 공통: 송출 전 미리보기 + 마이크 레벨 표시.
- 지원 환경: 시스템 소리는 Windows Chrome/Edge, 탭 소리는 데스크톱 Chrome/Edge, 모바일은 Android Chrome·iOS Safari(HTTPS).

### 시청·목록
- 시청: 처음엔 **음소거 자동재생 + "소리 켜기"**, 볼륨, 전체화면, simulcast 자동 화질, 제목·카테고리·닉네임·시청자 수·경과 시간, 채팅 패널(모바일은 영상 아래).
- 목록: 썸네일 카드 그리드. 썸네일은 **송출 중 브라우저가 주기적으로 캡처해 업로드**, 없으면 기본 이미지. 라이브 우선 → 시청자 수 순. 카테고리 필터(게임/버추얼/저스트채팅 등). **검색은 제목·닉네임·태그 부분 일치로 간단히**. 홈 그리드는 LIVE만(세부는 `features/02`).
- 스트리머 페이지: 닉네임, 현재 방송, 지난 방송·다시보기 목록, (팔로우 버튼), 스트리머용 관리 탭(후원 내역, 차단 목록).

## 6. 댓글(채팅)·모더레이션
- 시청 화면 옆 **실시간 채팅** 형태. **작성은 LIVE 중에만, 조회는 언제나**(종료·다시보기에서도 기록 열람).
- 수정 → "(수정됨)", 삭제 → "삭제된 메시지입니다"로 대체.
- 삭제 권한: **작성자 또는 방송 소유자**. 수정 권한: 작성자만.
- 200자 제한, 1초 1개 제한. 비로그인은 읽기만.
- **임시차단(1분/10분/1시간) + 영구 밴**, 그 스트리머의 **모든 방송**에 적용. 차단 목록·해제. 차단 사용자 입력창에 남은 시간 표시.

## 7. 도네이션·지갑
- 원장(ledger) 기반. **원장은 추가만, 수정·삭제 금지**. 잔액 차감은 `잔액 >= 금액` 조건부 UPDATE. 결제 확정은 `paymentKey`·`orderId` 유니크로 멱등.
- 후원 경로 2가지:
  1. **바로 결제 후원**(스펙 증명 경로): 서버가 금액·대상을 담은 대기 주문 생성 → 토스 결제 → 서버 승인 API로 금액·대상 대조 → 같은 트랜잭션에서 "충전 +N"(N = max(부족분, 1,000))과 "후원 -금액" 기록. 웹훅은 결제 조회 API로 재확인.
  2. **잔액 후원**: 충전(1,000/5,000/10,000/50,000비트) 후 잔액에서 차감.
- 예치금(충전·잔액)은 **도네이션 단계에서 함께 오픈**. 메인 상단에 잔액 표시.
- **환불 없음** (README에 "테스트 모드 충전은 환불 미지원" 명시).
- 원장 유형 `grant`(테스트 지급) — 로컬 QA 시드 전용, 운영 자동 지급 없음 (사용자 승인 11/11).
- 후원은 **LIVE 중에만**. 프리셋 1,000/5,000/10,000비트 + 직접 입력(1,000~1,000,000).
- 유료 클러치·SUPER BURST 비트는 **스트리머 후원으로 집계**. 정산·출금은 backlog.
- 후원 메시지는 채팅창 강조 + 시청자·송출 화면 알림.
- **익명 후원 지원**: 표시 이름은 내 닉네임 / 익명 두 가지. 시청자에게는 "익명의 후원자", **스트리머 관리 탭·집계에는 실제 닉네임**(밴 가능). 서버 API가 요청자 권한에 따라 가려서 내려준다.
- 공개 범위: 시청 화면에 방송 합계 + 최근 후원 목록, 스트리머는 방송별 전체 내역, 시청자는 "내 지갑"(충전·후원·클러치 사용 시간순 + 잔액).
- 스트리머 정산·출금 없음.

## 8. Clutch Time
- **클러치 버튼**(좋아요 대체): 30초에 5회까지 무료 콤보(COMBO x1~x5), **초과분은 1회당 1비트**(잔액 차감). 로그인 사용자만.
- **SUPER BURST**: 비트를 한 번에 써서 게이지를 크게 올림(+ 연출).
- 후원은 게이지에 반영하지 않는다. 비트로 게이지를 올리는 방법은 SUPER BURST뿐(금액 선택, 100%까지 남은 비트 표시). (사용자 결정 11/17)
- 게이지: **최근 5분 점수(감쇠형)**, 100% 기준은 고정값. 점수 배율·기준·콤보 제한·버스트 최소 금액은 **설정값**(수치는 features/07 "수치" 표).
- 100% → **"SUPER CLUTCH!"** 연출 → **5분간 "진행 중"**, 진행 중인 방송들을 메인 히어로에서 **30초씩 회전**(새 발동은 바로 다음 순서). 5분 대기열 방식은 터진 뒤 수십 분 뒤에 노출될 수 있어 폐기.
  - 방송 종료 → 즉시 제외. 히어로 패널에 진행 중 목록(최대 5개)으로 바로 이동.
  - 진행 중이거나 마지막 발동 후 30분 이내면 재등록 안 함.
  - 진행 중인 방송이 없으면 **게이지가 가장 높은 라이브**가 히어로(모두 0이면 시청자 수 1위). 히어로 오른쪽에 CLUTCH TIME 패널이 붙는다.
  - 발동 시각·회전 순서는 DB 저장, 백그라운드 작업이 1초 단위로 진행(재시작 안전).
- **CLUTCH FEED**: Super Clutch 시점 기준 **가상 클립**(다시보기 영상 + 시작 시각 + 길이, 발동 30초 전~15초 후). 녹화 파일 완성 후 노출. 그 전엔 "최근 다시보기".

## 9. 녹화·다시보기
- **LiveKit Egress로 방 전체 MP4** 저장 → **Oracle Object Storage**(S3 호환).
- 방송 등록 시 "녹화" 체크박스(기본 켜짐). 방송 1회 최대 3시간, 30일 보관, 녹화 합계 16GB(백업 공간 여유)를 넘으면 오래된 것부터 삭제.

## 10. 팔로우
- 팔로우 테이블은 초기 스키마부터 생성. 기능은 녹화 다음 단계.
- **PULSE = 내가 팔로우한 채널 모음.** 버튼(행동)은 "팔로우" 그대로, 모이는 곳(사이드바 섹션·메뉴·페이지)은 PULSE. 비로그인 사이드바는 "인기 라이브". 방송 알림(푸시·이메일) 없음.

- Git: **GitHub Flow**, 기능 1개 = PR 1개, **Squash merge**, CI 통과 + 메인 세션의 보고서·docs 판단 후 메인 세션이 머지(`gh pr checks --watch` → `gh pr merge --squash`). 비공개 무료 저장소라 branch protection·auto-merge는 쓸 수 없다. 저장소는 개발 중 비공개 → 제출 전 공개(공개 직전 gitleaks 스캔).
- 커밋: Conventional Commits, 타입·범위 영어 + 설명 한국어, 본문에 처리 사항 bullet.
- 코드 작성 원칙: 최소 코드(YAGNI) — 단, 신뢰 경계 검증·권한·돈·데이터 손실 처리는 줄이지 않는다.

## 14. 기술 기본값 (사전 점검 2026-11-09)
- ID `BIGINT` identity, 비트 `BIGINT`, 시간 UTC 저장·날짜 경계 KST, ts-rs i64 → `number`. 상세는 `architecture.md` §7-1.
- 원장: 스트리머는 받은 비트를 적립받지 않는다(정산 없음). 차감은 조건부 UPDATE … RETURNING.
- 세션: 32바이트 랜덤 토큰 쿠키 `flutch_session`, DB에는 SHA-256 해시.
- WebSocket: Origin 검사 + 쿠키로 사용자 식별, **연결별 필터링**(익명 후원자 실명은 소유자 연결만). 홈은 WebSocket 없이 10초 폴링.
- 토스 웹훅: 서명 대신 결제 조회 API로 재확인. 결제위젯 키 사용.
- 로컬 개발: compose.dev에 로컬 LiveKit 서버. CI: Postgres service + `SQLX_OFFLINE`. 이미지: `ubuntu-24.04-arm` 러너 네이티브 빌드.
- 후원 TTS 추가(2026-11-19 사용자 결정): backlog에서 범위로 올림. 브라우저 `speechSynthesis`, 프론트 전용, 익명은 공개 이름만 → [features/06](features/06-wallet-donation.md).
