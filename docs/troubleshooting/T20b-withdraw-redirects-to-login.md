# 탈퇴 성공 후 홈 대신 로그인 화면으로 튕김
- task: T20b · PR: (이 PR) · 날짜: 2026-11-10
- 영역: frontend/features/auth

## 증상
내 정보에서 탈퇴에 성공하면 홈(`/`)으로 가야 하는데 `/login?next=%2Fme`로 이동했다.

## 원인
성공 처리에서 `me` 캐시를 먼저 null로 비우고 `navigate('/')`를 불렀다. react-query 갱신은 바로 다시 그리지만 라우터 이동은 transition이라 늦게 반영돼, 그 사이 `/me` 화면의 `useRequireLogin`이 "비로그인"으로 보고 로그인 화면으로 보냈다(나중 이동이 이김).

## 해결
탈퇴 성공 시 `window.location.replace('/')`로 홈을 새로 불러온다. 페이지가 새로 열리므로 캐시도 전부 비워진다(`useWithdraw`).

## 재발 방지
- 로그인이 필요한 화면에서 로그아웃·탈퇴 뒤 다른 곳으로 보낼 때는 `me`를 비우기 전에 그 화면을 벗어나거나, 새로 불러온다.
- 같은 구조인 `useLogoutToHome`(내 정보의 "로그아웃")도 같은 경쟁이 있을 수 있다(이번 범위 밖, 확인 안 함).
