# 병렬 worktree 화면 확인 중 갑자기 401(로그인이 필요합니다)
- task: T09c · PR: (이 PR) · 날짜: 2026-11-10
- 영역: 개발 환경(여러 worktree의 Browser 확인)

## 증상
스튜디오에서 방송 시작을 누르면 `POST /broadcasts/{id}/live` 가 401, 화면에 "로그인이 필요합니다". 헤더에는 로그인된 것처럼 보였다.

## 원인
세션 쿠키는 포트를 구분하지 않아 `localhost:5193`·`localhost:5xxx`가 같은 쿠키를 쓴다. 다른 worktree의 Browser 확인이 로그인하면서 내 쿠키를 덮어썼고, 그 세션은 내 DB에 없다.

## 해결
요청 직전에 `POST /api/v1/auth/test-login` 으로 다시 로그인한 뒤 바로 진행했다.

## 재발 방지
병렬 task가 동시에 화면 확인을 할 때 401이 나오면 코드 문제로 보기 전에 다시 로그인한다. 긴 흐름은 로그인 직후 바로 수행한다.
