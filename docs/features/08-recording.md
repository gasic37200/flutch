# 08. 녹화·다시보기

## 녹화
- 방송 등록 시 "녹화" 체크(기본 켜짐). LIVE 시작 시 **LiveKit Egress로 방 전체 MP4** → Oracle Object Storage(S3 호환).
- 최대 3시간(방송 길이와 동일).
- 종료 후 파일 준비 전: "다시보기 처리 중". 준비 완료 웹훅 → 영상 위치·길이 저장.
- 실패: 방송은 정상 ENDED, 다시보기 없음, 스트리머 관리 화면에 "녹화에 실패했어요". **자동 재시도 없음.** 녹화 상태는 방송 상태와 분리.

## 다시보기
- **누구나 시청**(비로그인 포함). 비공개 옵션 없음, 숨기려면 방송 삭제(=숨김 + 파일 삭제).
- 보관: **30일** 후 자동 삭제 + 저장 용량 18GB 초과 시 오래된 것부터. 삭제 후 "보관 기간이 지난 다시보기예요".
- 플레이어: 탐색, **배속 0.5~2배**, 볼륨, 전체화면. 이어보기 없음.
- 썸네일: 라이브 마지막 캡처 재사용.
- 조회수: 같은 시청자(사용자 id 또는 브라우저 익명 id) **하루 1회**.
- 채팅: 전체 목록(동기화 리플레이 없음).

## 목록
- 다시보기 메뉴: 최신순, 카테고리 필터. 스트리머 페이지: 그 스트리머의 다시보기.
- 카드: 썸네일, 길이, 제목, 닉네임, 최고 시청자 수, 조회수, 날짜.
