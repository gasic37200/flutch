# 02. 방송 관리

## 상태
`등록 → READY(준비) → 송출 시작 → LIVE → 종료 → ENDED`
- READY: 등록만 하고 송출 전. 목록·검색에 안 나옴, 본인 관리 화면에만.
- ENDED는 최종 상태. 새로 방송하려면 새로 등록("이전 방송 정보 복사" 제공).
- 사용자당 **동시 LIVE 1개**, **READY 최대 5개**(자동 삭제 없음).
- 다른 전이는 409.

## 등록 항목
| 항목 | 규칙 |
|---|---|
| 제목 | 필수, 2~50자, 욕설·FLUTCH 금지어 포함 시 거절 |
| 카테고리 | 필수, 고정 8개: 저스트채팅, 종합게임, FPS, RPG, 공포게임, 버추얼, 스포츠, 음악 (코드 상수) |
| 태그 | 최대 3개, 태그당 10자, 금지어 차단. 게임 이름은 태그로 |
| 녹화 | 체크박스, 기본 켜짐 |
설명·연령 제한 없음.

## 상태별 수정
| 상태 | 수정 가능 |
|---|---|
| READY | 전부 |
| LIVE | 제목, 카테고리, 태그 (시청자 화면·목록에 실시간 반영). 녹화 여부 변경 불가 |
| ENDED | 제목만 |

## 삭제
- 스트리머가 관리 화면에서 직접 삭제.
- READY: 완전 삭제.
- LIVE: 송출 강제 종료 → ENDED 규칙.
- ENDED: **숨김 처리**(목록·검색·스트리머 페이지에서 제외) + **녹화 파일 저장소에서 삭제**. 채팅·후원·원장은 보존, 후원자 지갑 내역엔 "삭제된 방송".

## 길이 제한
- **방송 1회당 최대 3시간**. 10분 전 스트리머 화면 경고, 3시간에 자동 종료. 녹화도 동일. (설정값)
- 사람당 하루 한도 없음.

## 목록·검색
- 홈 그리드: LIVE만, 시청자 수 순. 카테고리 칩 필터.
- 카드: 썸네일, LIVE 배지, 시청자 수, 카테고리, 제목, 스트리머 닉네임·프로필, 경과 시간.
- 검색: 제목·닉네임·태그 부분 일치(간단히). LIVE 우선, 이어서 다시보기.
- 썸네일: 송출 중 브라우저가 **1분마다** 캡처 업로드(최신 1장만 보관). 없으면 기본 이미지(배경 텍스처 + 카테고리 + 고양이).

## 시청자 수
- 현재 접속 시청자, **스트리머 제외, 비로그인 포함, 중복 제거**(로그인=사용자 id, 비로그인=브라우저 익명 id).
- LiveKit 접속 신원은 `사용자id:탭id`(같은 신원 재접속 시 기존 연결이 끊기는 문제 회피), 셀 때 사용자 단위로 묶음.
- 종료 후: **최고 동시 시청자 수** 저장·표시. 시청자 목록 없음.

## 시나리오 테스트
- `broadcast_owner_crud`: 등록 → 수정 → 삭제
- `broadcast_other_user_forbidden`: 다른 사용자 수정·삭제·송출 시작 403, 비로그인 401
- `broadcast_public_read`: 비로그인 목록·상세 200
- `broadcast_state_transitions`: 허용 전이만 성공, ENDED→LIVE 409, LIVE 중 제목만 수정, ENDED는 제목만
- `broadcast_limits`: 동시 LIVE 2개 거절, READY 6개째 거절
- `broadcast_delete_live_ends_first`
