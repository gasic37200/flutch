# 05. 모더레이션

## 차단 종류
- **임시차단**: 1분 / 10분 / 1시간, 시간이 지나면 자동 해제.
- **영구 밴**: 스트리머가 해제할 때까지.
- 적용 범위: 그 스트리머의 **모든 방송**. 매니저 없음(스트리머 본인만).

## 효과
| 동작 | 임시차단 | 영구 밴 |
|---|---|---|
| 시청 | 가능 | 가능 |
| 채팅 | 불가 | 불가 |
| 무료 클러치 | 가능 | 가능 (익명 게이지라 노출 없음) |
| 유료 클러치·SUPER BURST | 가능 | 불가 |
| 후원 | 가능 | 불가 |
- 차단 사용자 입력창: "n분 후 채팅할 수 있어요" / "이 채널에서 채팅이 제한되었어요".

## 차단할 때
- 채팅창 시스템 메시지: "OOO님의 채팅이 10분간 제한되었어요" / "OOO님이 차단되었어요" (사유 미표시).
- **영구 밴 시 그 사람의 현재 방송 메시지를 자동으로 "삭제된 메시지"로.**
- 사유 메모 없음.

## 스트리머 도구
- 채팅 닉네임 클릭 → (스트리머에게만) 임시차단·영구 밴·**"이 시청자의 채팅 기록"**(내 방송들에서 쓴 채팅, 커서 페이지네이션).
- 후원 내역에서도 바로 차단(익명 후원자 포함, 실명 기준).
- 관리 탭: 차단 목록(남은 시간), 영구 밴 해제.
- 차단·해제 이력은 추가만 하는 테이블로 보존.

## FLUTCH 금지어
- 저장소 파일(`backend/data/banned_words.txt`)로 관리, 배포 시 반영.
- 적용: 채팅, 닉네임, 방송 제목·태그. 처리: **차단**.
- 일반 욕설 목록은 가림(채팅) / 거절(닉네임). 목록 출처는 README에 표기.
