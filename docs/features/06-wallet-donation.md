# 06. 지갑·후원

화폐: **비트(beat), 1비트 = 1원**. 결제: 토스페이먼츠 테스트 모드.

## 원장 원칙
- 원장(ledger)은 **추가만**. 수정·삭제 금지. 유형: 충전, 테스트 지급, 후원, 유료 클러치, SUPER BURST, 탈퇴 소멸.
- 테스트 지급(`grant`, +)은 **로컬 QA 시드 전용**(`backend/scripts/seed_qa.sql`, psql로 수동 실행). 운영에는 자동 지급 경로가 없다. 지갑 내역에 "테스트 지급"으로 표시.
- 잔액 차감은 `UPDATE ... WHERE balance >= $amount` 조건부로만. 잔액과 원장 합계는 항상 일치.
- 결제 확정은 `paymentKey`·`orderId` 유니크로 멱등(같은 승인 통지·웹훅이 여러 번 와도 1번만 적립). 웹훅은 서명이 아니라 **결제 조회 API로 재확인**.
- 스트리머는 받은 비트를 원장에 적립받지 않는다. 받은 합계는 후원 기록에서 집계.

## 충전
- 프리셋 1,000 / 5,000 / 10,000 / 50,000 + 직접 입력. 1회 **1,000 ~ 1,000,000**, 보유 상한 **3,000,000**.
- 흐름: 서버가 대기 주문 생성 → 토스 결제 → 서버 승인 API(금액 대조) → 원장 "충전".
- 대기 주문은 **30분 후 만료**, 만료 주문 승인 요청은 거절.
- **환불 없음**("테스트 모드 충전은 환불을 지원하지 않습니다").

## 후원
- **LIVE 중에만**. 금액 **1,000 ~ 1,000,000**. 메시지 선택, **최대 100자**, 욕설 가림 + FLUTCH 금지어 차단.
- 표시 이름: **내 닉네임 / 익명** 두 가지(직접 입력 이름은 사칭 위험으로 제외).
- 흐름(치지직·숲과 같은 충전형):
  1. 잔액이 충분 → 잔액에서 바로 후원.
  2. 잔액 부족 → **"N비트 충전하고 후원하기"**(N = max(부족분, 1,000), 최소 충전 단위 때문에 남는 비트는 잔액에 남음) → 토스 결제 → 서버가 승인 시 금액·대상·방송 상태 확인 → 같은 트랜잭션에서 "충전 +N"과 "후원 -금액" 기록. (스펙의 결제 승인→확인→확정 경로)
- 승인 시점에 방송이 이미 종료됐으면: **후원 없이 충전만** 하고 "방송이 종료되어 잔액으로 충전했어요".
- 영구 밴된 사용자는 그 스트리머에게 후원 불가.

## 후원 알림
- 시청자 화면·스트리머 송출 화면에 **10초**, 여러 건이면 **순서대로**.
- **스트리머가 스킵** → 서버가 모든 시청자에게 스킵 이벤트.
- 10,000비트 이상 큰 연출. 채팅창에 강조 한 줄.
- 익명 후원은 시청자에게 "익명의 후원자"(알림·채팅·후원 목록 모두).

## 조회
- 끝난 방송·다시보기 상세에도 그 방송의 후원 합계와 목록을 보여준다(스펙 "방송별 후원 내역과 합계").
- 시청 화면: 방송 합계 + 최근 후원 목록(표시 이름, 비트, 메시지). 유료 클러치·버스트도 합계에 포함.
- 스트리머 관리 탭: 방송별 합계·건수·전체 내역(**익명 후원자도 실명**), 누적 받은 비트, 최근 7일 합계. 후원자 순위 없음.
- 내 지갑: 잔액 + 충전 버튼, 내역(유형·월 필터). 유료 클러치는 **방송별로 묶어 한 줄**(원장은 건별, 화면에서만 묶음).
- 후원자 배지: 이 방송에 후원한 사람(익명 포함).

## 범위 밖 → [backlog](../backlog.md)

## 시나리오 테스트
- `donation_confirm_idempotent`: 같은 승인·웹훅 3번 → 적립 1번
- `donation_amount_mismatch_rejected`: 주문과 다른 금액 승인 거절
- `donation_balance_conditional_debit`: 동시 차감 2건 중 잔액 초과분 거절, 음수 잔액 없음
- `donation_live_only` / `donation_after_end_becomes_charge`
- `donation_anonymous_name_visibility`: 시청자 응답엔 익명, 소유자 응답엔 실명
- `charge_limits_and_order_expiry`
- `banned_user_cannot_donate`
- `wallet_grant_credits_and_appends_only`: 테스트 지급이 잔액·내역(type grant)에 반영, 수정·삭제 불가, 주문·방송 참조·음수 거절
- `wallet_qa_seed_runs_once`: 시드 계정 없으면 에러, 두 번 실행해도 한 번만 들어가고 잔액 = 원장
