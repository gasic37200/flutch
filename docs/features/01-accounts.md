# 01. 계정·인증

## 가입
- 입력: 아이디, 비밀번호, 닉네임 + **이용약관·개인정보처리방침 필수 동의 + 만 14세 이상 확인**. 마케팅 동의 없음.
- 본인 확인(이메일·휴대폰) 없음. 가입 즉시 로그인 상태.
- 아이디: 4~20자, 영문 소문자·숫자, 대소문자 무시 중복 검사, **변경 불가**, 탈퇴한 아이디는 **영구 재사용 불가**.
- 비밀번호: 8~64자, **영문+숫자 필수**, 아이디와 동일 금지, 흔한 비밀번호 상위 100개 차단. argon2 해시.
- 닉네임: 2~12자, 한글·영문·숫자(공백·특수문자 불가), 중복 불가, 예약어(운영자·관리자·FLUTCH·플러치·admin·system 등) 불가, 욕설 목록·FLUTCH 금지어 불가.
- 가입 남용 방지: **같은 IP에서 1시간에 5회** 초과 시 429.
- 약관 페이지 2개(짧은 기본 문안, "공모전 시연용" 명시).

## 로그인·세션
- 서버 세션(Postgres) + httpOnly·Secure·SameSite=Lax 쿠키.
- 유지: **기본 7일(사용 시 연장)**, "로그인 상태 유지" 체크 시 **30일**. LIVE 송출 중에는 만료되지 않음.
- 동시 로그인 허용. **비밀번호 변경 시 현재 기기 외 세션 전부 만료.**
- 실패 제한: 같은 아이디 **5회 연속 실패 → 5분 잠금**(남은 시간 표시), 같은 IP **1분 20회 초과 → 차단**.
- 실패 메시지는 "아이디 또는 비밀번호가 올바르지 않아요"로 통일.
- 로그아웃: 서버 세션 즉시 삭제.

## 테스트 계정
- 시드: 스트리머1, 스트리머2, 시청자. 서버 시작 시 "없으면 생성"(마이그레이션 아님). 비밀번호는 환경변수.
- 로그인 화면 **"테스트 계정으로 바로 로그인"** 버튼 3개.
- 시드 계정은 여러 심사자가 함께 쓰므로 닉네임·비밀번호를 바꿀 수 없다(403 `AUTH_SEED_ACCOUNT_LOCKED`). 테스트 로그인도 로그인과 같은 IP 한도를 받는다.

## 내 정보
- 닉네임 변경: **변경 후 30일 재변경 불가**(가입 시 설정은 제외), 남은 일수 표시.
- 비밀번호 변경: 현재 비밀번호 확인.
- 기본 프로필: 마스코트 얼굴 + 배경색 6종(사용자 id로 고정). 업로드 없음.

## 탈퇴
- 비밀번호 재확인 → 로그인 불가, 세션 전부 만료, 닉네임은 "탈퇴한 사용자"로 표시.
- **LIVE 중이면 탈퇴 불가**(먼저 종료).
- **잔액이 있으면 "남은 N비트는 사라지고 되돌릴 수 없어요" 경고 후 확인** → 원장에 "탈퇴 소멸 -N" 추가 후 탈퇴.
- 채팅·후원·원장 기록은 보존("탈퇴한 사용자"). 닉네임은 **30일 후 해제**.
- 준비 중(READY) 방송은 탈퇴와 함께 지운다(기록이 생길 수 없는 방송). 끝난 방송은 남는다(T20b).
- 재가입은 새 아이디로 즉시 가능(본인 확인이 없어 동일인 판별 불가 → README 알려진 한계).

## 카카오 로그인 (녹화 단계 다음)
- 요청 정보: 닉네임만(이메일 미요청).
- 첫 로그인: 카카오 닉네임을 미리 채운 **닉네임 설정 화면** → 위 닉네임 규칙 검사.
- 기존 아이디 계정과 연결 없음. 카카오 계정은 비밀번호 변경 메뉴 숨김.
- 보안: `state`로 CSRF 방지, 비밀키는 서버 환경변수, 콜백 주소 화이트리스트. 로그인 후에는 동일한 FLUTCH 세션.
- 탈퇴 시 카카오 연결 해제(unlink).

## 범위 밖 → [backlog](../backlog.md)
비밀번호 찾기, 다른 기기 모두 로그아웃 버튼, 프로필 사진 업로드.

## 시나리오 테스트
- `auth_signup_login_logout`: 가입 → 로그인 → 내 정보 → 로그아웃 후 401
- `auth_lockout`: 5회 실패 → 잠금 → 5분 후 해제
- `auth_password_change_revokes_other_sessions`
- `auth_nickname_change_30day_limit`
- `auth_withdraw_forfeits_balance`: 잔액 소멸 원장 기록, 탈퇴 후 로그인 불가, 아이디 재가입 불가
- `auth_withdraw_rules`: LIVE 중·잔액 확인 없음 409, 테스트 계정 403, 잔액 0이면 원장 없이 탈퇴
