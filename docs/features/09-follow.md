# 09. 팔로우·스트리머 페이지

## 팔로우 (녹화 단계 다음)
- 로그인 사용자, 스트리머 페이지의 팔로우 버튼. 자기 자신 불가, 개수 제한 없음, 언제든 취소.
- 팔로워 수 공개, 팔로워 목록 비공개(스트리머 본인도 숫자만).
- 팔로우 테이블은 초기 스키마부터 생성.
- 알림(푸시·이메일·사이트 내 종 아이콘) 없음.

## PULSE (팔로우한 채널 모음)
- 이름 규칙: 버튼은 **"팔로우 / 팔로우 취소"**, 모이는 곳은 **PULSE**(사이드바 섹션, 왼쪽 메뉴, `/pulse` 페이지). "펄스하기" 같은 동사는 쓰지 않는다.

### 사이드바 PULSE
- 로그인 + 팔로우 있음: 라이브 팔로우 채널(시청자 수 순) → 오프라인 팔로우 채널(회색), 합쳐서 최대 10개 + "더보기".
- 팔로우 단계(T27) 전: 모든 사용자에게 "인기 라이브" 섹션으로 표시.
- 비로그인: 섹션 제목을 **"인기 라이브"**로 바꾸고 상위 5개 + "로그인하면 내 PULSE가 보여요".
- 로그인 + 팔로우 0개: PULSE 제목 + "스트리머를 팔로우하면 여기서 맥박이 뛰어요" + 인기 라이브 3개.
- 섹션 맨 아래 **"PULSE 전체 보기 →"** → PULSE 페이지.

### PULSE 페이지 `/pulse` (왼쪽 메뉴 "PULSE")
- 제목 PULSE, 부제 "내가 팔로우한 채널 N".
- 지금 방송 중(라이브 카드, SUPER CLUTCH 진행 중 배지) → 오프라인(마지막 방송 시점, 팔로워 수, 다시보기, 팔로우 취소).
- 팔로우 0개: 빈 화면 + "탐색하기".

## 스트리머 페이지 `/users/{id}`
- 닉네임, 프로필, 팔로워 수, 팔로우 버튼, 현재 방송, 지난 방송·다시보기 목록.
- 본인에게만 관리 탭: 방송 관리(READY 포함), 후원 내역·통계, 차단 목록.
