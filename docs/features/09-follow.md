# 09. 팔로우·스트리머 페이지

## 팔로우 (녹화 단계 다음)
- 로그인 사용자, 스트리머 페이지의 팔로우 버튼. 자기 자신 불가, 개수 제한 없음, 언제든 취소.
- 팔로워 수 공개, 팔로워 목록 비공개(스트리머 본인도 숫자만).
- 팔로우 테이블은 초기 스키마부터 생성.
- 알림(푸시·이메일·사이트 내 종 아이콘) 없음.

## 사이드바 PULSE
- 로그인 + 팔로우 있음: 라이브 팔로우 채널(시청자 수 순) → 오프라인 팔로우 채널(회색), 합쳐서 최대 10개 + "더보기".
- 비로그인·팔로우 없음·팔로우 단계 전: 인기 라이브 상위 5개.
- 팔로잉 메뉴: 팔로우 목록(라이브 먼저).

## 스트리머 페이지 `/users/{id}`
- 닉네임, 프로필, 팔로워 수, 팔로우 버튼, 현재 방송, 지난 방송·다시보기 목록.
- 본인에게만 관리 탭: 방송 관리(READY 포함), 후원 내역·통계, 차단 목록.

## 시나리오 테스트
- `follow_toggle_and_count`
- `follow_self_rejected`
