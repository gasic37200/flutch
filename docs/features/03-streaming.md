# 03. 송출·시청

## 송출 모드 (앱 설치 없이 브라우저)
| 기기 | 모드 | 화질 상한 |
|---|---|---|
| PC | **화면 공유** + 마이크 (+ 탭 소리 / 시스템 소리) | 1080p 30fps |
| PC | **웹캠 모드** (카메라 + 마이크, 모바일과 같은 코드) | 720p 30fps |
| 모바일 | 카메라(전/후면 전환) + 마이크 | 720p 30fps |
- PC 송출 화면에서 화면 공유 ↔ 웹캠 모드 전환.
- **화면 + 웹캠 동시(PIP)**: 화면 공유 중 웹캠을 켜면 카메라 트랙(360p30)을 따로 보내고 시청자 화면에서 모서리에 겹쳐 표시. 위치는 스튜디오 "배치 편집"에서 스트리머가 자유 배치(후원 알림·채팅 오버레이도 함께, 영상 기준 %, 방송별 저장·새 방송은 마지막 배치를 이어받음), 송출 중 켜기·끄기 가능, 화면 공유가 끊기면 카메라를 크게. 시청자는 PIP 숨기기 가능. 녹화는 LiveKit 기본 배치. 상세는 `docs/architecture.md` §9.
- 모바일은 화면 공유 미지원 → 자동으로 카메라 모드.
- 화질 선택 옵션 없음. 시청자 쪽은 simulcast로 자동 조절.

## 송출 화면
- 송출 전 **미리보기** + 마이크·화면 소리 **레벨 미터**.
- PC: **마이크 볼륨·화면 소리 볼륨 슬라이더** + 각각 음소거, 화면 소스 변경. (Web Audio GainNode, PC Chrome/Edge 전용)
- 모바일: 카메라 전환, 마이크 음소거, Wake Lock.
- 마이크: 잡음 제거·에코 제거·자동 볼륨 켬. 화면 소리: 처리 없음.
- 3시간 10분 전 경고.

## 권한·토큰
- `POST /broadcasts/{id}/live`: 로그인 + 소유자만 → publish 토큰. 서버가 LIVE 전이.
- 시청 토큰: 누구나, subscribe 전용.
- 종료: 서버가 LiveKit 방을 닫아 송출을 실제로 끊음.

## 끊김·복구
| 상황 | 동작 |
|---|---|
| 화면 공유만 끊김("공유 중지") | **방송 유지**, 시청자에게 "잠시 화면 공유가 중단됐어요", 마이크는 계속, 스트리머에게 "다시 공유하기" |
| 송출자 연결 끊김(탭 닫기·네트워크) | LiveKit 웹훅 감지 → **60초 유예** → 미복귀 시 자동 ENDED. 유예 중 시청자에게 "재연결 대기" |
| 유예 중 스트리머 복귀 | "방송을 이어서 할까요?" → 같은 방송으로 재송출, 시청자 자동 복귀 |
| 다른 기기에서 같은 방송 송출 시도 | **확인 후 새 기기로 전환**(서버가 기존 송출자 연결 끊고 새 토큰 발급) |
| 서버 재시작 | 시작 시 LiveKit 실제 방 상태와 DB 동기화 |

## 시청 화면
- 처음엔 **음소거 자동재생 + "소리 켜기"**, 볼륨, 전체화면.
- 영상 아래 **가로 Clutch 게이지 바**(오른쪽 끝에 클러치·SUPER BURST 버튼) → 방송 정보(제목·카테고리·태그·시청자 수·경과 시간) → 채팅(데스크톱은 오른쪽 패널, 모바일은 아래).
- 채팅 오버레이: 스트리머 배치대로 영상 위에 최근 채팅(일반 화면 4줄·영상 폭 600px 이하 3줄·한 줄 말줄임, 전체화면 6줄, 후원 줄 강조). 컨트롤 줄 "채팅" 토글로 시청자가 끄고 켠다(기본 켬, 브라우저에 기억). 일반 화면은 옆·아래 채팅 패널도 그대로.
- 전체화면: 스트리머 배치대로 웹캠·후원 알림·채팅 오버레이.
- READY 방송 링크: **"곧 방송이 시작돼요"** 대기 화면 → 시작되면 자동 재생.
- 종료 시: "방송이 종료되었어요" + 최고 시청자 수·방송 시간, 녹화 켜짐이면 "다시보기 준비 중" → 준비되면 "다시보기 보기".
- 시청자 네트워크 끊김: LiveKit 자동 재연결 + "재연결 중" 표시.

## 지원 환경 안내 (송출 화면 진입 시 검사)
- 시스템 소리 미지원(맥, Firefox 등): "이 환경에서는 탭 소리만 송출할 수 있어요"
- 화면 공유 미지원: 카메라 모드로 자동 전환
- 권한 거부·HTTPS 아님: 권한 허용 방법 안내
- README "지원 환경" 표와 같은 기준

## 시나리오 테스트
- `live_start_owner_only`: 소유자만 publish 토큰, 다른 사용자 403, 비로그인 401
- `live_end_closes_room`: 종료 시 ENDED + 방 닫기 호출
- `live_disconnect_grace_auto_end`: 퇴장 웹훅 → 60초 → ENDED / 60초 안 복귀 시 유지
- `live_takeover_other_device`
- `live_max_duration_auto_end`
- `broadcast_overlay_layout_owner_only`: 오버레이 배치 — 소유자만 수정(다른 사용자 403), 범위 밖 422, READY·LIVE 수정·ENDED 409, 새 방송이 마지막 배치 복사
- `live_webhook_signature_invalid_rejected`
