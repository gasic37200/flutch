# 07. Clutch Time

## 클러치 버튼 (좋아요 대체)
- 로그인 사용자만. **30초에 5회까지 무료**(COMBO x1~x5, 내 화면에만 표시), **초과분은 1회 1비트**(잔액 차감).
- 표시: **익명** — 다른 사람에게는 게이지가 오르는 것만 보임.
- 유료 클러치 비트는 **스트리머 후원으로 집계**(알림 없음, 합계에만).

## SUPER BURST
- 비트를 한 번에 써서 게이지를 크게 올림(가격 설정값) + 연출. 스트리머 후원으로 집계, 후원 알림에 표시 이름(닉네임/익명).

## 게이지
- 점수: 무료 클러치·유료 클러치·버스트·후원 비트를 합산(배율 설정값). **최근 5분 점수(감쇠형)**, 100% 기준 고정값(설정값).
- 표시: **퍼센트만**. 시청 화면 영상 아래 가로 바, 홈 히어로 오른쪽 CLUTCH TIME 패널에는 히어로 방송의 게이지.

## SUPER CLUTCH
- 100% → 그 방송 시청자 전원에게 **3초 전체 화면 연출(소리 없음)**, **게이지 0% 초기화**, 대기열 등록.
- 대기열에 있거나 노출 후 30분 이내면 재등록 안 함("쿨다운 중" 표시, 게이지는 오름).

## 메인 히어로·대기열
- 대기열 순서대로 **5분씩** 메인 히어로 노출: 라이브 영상(음소거) + SUPER CLUTCH 배지 + 남은 시간 바.
- 히어로 아래 "다음 클러치" 최대 3개 공개.
- 노출 중 종료 → 즉시 다음. 대기 중 종료 → 제거. 대기열이 비면 **게이지 1위 라이브**(모두 0이면 시청자 수 1위, 배지 없음).
- DB 저장 + 백그라운드 작업 1초 단위 진행(재시작 안전).

## 히어로 오른쪽 CLUTCH TIME 패널
히어로 영상 오른쪽에 붙는 패널. 홈의 별도 CLUTCH TIME 패널은 없애고 오른쪽 열은 "추천 라이브 채널"만 둔다.
| 상태 | 패널 | 문구 |
|---|---|---|
| 충전 중 (0~79%) | CLUTCH TIME 로고타입 + 히어로 방송 게이지 | "지금, 클러치할 시간!" → 시청 화면으로 이동 |
| 임박 (80~99%) | 로고·게이지 맥박 연출, 심박 라인 빨라짐 | "곧 터져요!" |
| SUPER CLUTCH 노출 중 | SUPER CLUTCH 카드: 배지, 남은 노출 시간 바, 다음 클러치 3개 | — |
| 쿨다운 | 로고 흐리게 + 게이지 | "다음 클러치까지 n분" |
| 라이브 없음 | 로고 + 졸린 표정 마스코트 | "첫 번째 클러치를 만들어 보세요" + 방송하기 |
- 임박 기준(80%)은 설정값.
- CLUTCH TIME 로고타입은 홈 히어로 패널, 시청 화면 게이지 바 라벨, SUPER CLUTCH 연출에서만 쓴다.

## CLUTCH FEED (가상 클립)
- SUPER CLUTCH 발동 시각 기준 **발동 30초 전 ~ 15초 후** 구간을 "다시보기 + 시작 시각 + 길이"로 저장. 녹화가 켜진 방송만, 녹화 파일 완성 후 노출.
- 그 전까지는 홈 CLUTCH FEED 자리에 "최근 다시보기".

## 수치 (설정값, 추후 결정)
무료 클러치 점수, 유료 클러치 점수, 버스트 가격·점수, 후원 비트 배율, 100% 기준, 감쇠 창(5분).

## 시나리오 테스트
- `clutch_free_combo_then_paid`: 6번째부터 1비트 차감, 잔액 부족 시 거절
- `clutch_gauge_decay_window`
- `super_clutch_trigger_reset_and_cooldown`
- `clutch_queue_rotation`: 5분 순환, 종료 시 즉시 다음, 대기 중 종료 제거
- `clutch_banned_rules`: 영구 밴 무료 가능·유료 불가
