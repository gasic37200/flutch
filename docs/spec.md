# 공모전 원문 요구사항

> 이 문서는 공모전 공고 원문이다. 모든 판단에서 이 문구가 우선한다. 수정하지 않는다.

## 1. 공모 주제
치지직과 같은 실시간 라이브 방송을 송출하고 시청할 수 있는 웹 서비스를 개발합니다.

## 2. 필수 요구사항

### 2-1. PC 라이브 방송
- PC 화면 공유와 마이크를 이용해 라이브 방송을 시작하고 종료합니다.
- 화면 공유 시 탭 소리 또는 시스템 소리를 마이크 음성과 함께 송출합니다.
- PC에서 송출한 방송을 다른 기기에서 실시간으로 시청합니다.
- 방송 시작, 화면 공유, 소리 송출, 시청, 종료 흐름을 확인합니다.

### 2-2. 모바일 라이브 방송
- 휴대폰 카메라와 마이크로 라이브 방송을 시작하고 종료합니다.
- 카메라 영상과 마이크 음성을 실시간으로 송출합니다.
- 휴대폰에서 송출한 방송을 다른 기기에서 시청합니다.
- 방송 시작, 영상 및 음성 송출, 시청, 종료 흐름을 확인합니다.

### 2-3. 방송 관리 및 시청
- 방송 제목 등 방송 정보를 등록, 수정, 삭제합니다.
- 방송 목록과 상세 화면을 제공하고 원하는 방송을 선택해 시청할 수 있게 합니다.
- 방송 중과 종료 상태를 구분하고, 방송 종료 시 송출을 중단합니다.
- 방송 정보를 저장하고 서버 재시작 후에도 조회할 수 있게 합니다.

### 2-4. 사용자 인증 및 인가
- 회원가입, 로그인, 로그아웃과 인증 상태 관리를 구현합니다.
- 로그인한 사용자만 방송을 등록하고 송출할 수 있게 합니다.
- 방송 수정, 삭제 및 송출 제어 시 서버에서 인증 상태와 방송 소유자 권한을 확인합니다.
- 비로그인 사용자, 방송 소유자, 다른 사용자로 나눠 접근 허용과 거절을 확인합니다. 방송 목록 조회와 시청은 로그인 없이 가능합니다.

## 3. 선택 요구사항 (가산점)

### 3-1. 댓글
- 로그인한 사용자가 방송별 댓글을 작성하고 댓글 목록을 조회할 수 있게 합니다.
- 댓글 수정과 삭제 기능을 구현하고 서버에서 작성자 권한을 확인합니다.

### 3-2. 도네이션
- 로그인한 사용자가 후원할 방송자와 금액을 선택합니다.
- 결제 서비스의 테스트 모드에서 결제를 요청하고, 서버에서 승인 결과, 금액, 후원 대상을 확인한 뒤 후원을 확정합니다.
- 같은 승인 통지가 반복되어도 한 번만 적립되도록 처리하고, 방송별 후원 내역과 합계를 표시합니다.

### 3-3. 녹화 및 다시보기
- 라이브 방송을 녹화 영상으로 저장합니다.
- 녹화 영상 목록과 상세 화면을 제공하고 영상을 재생합니다.
- 방송 정보와 영상 위치를 저장하고 서버 재시작 후에도 조회할 수 있게 합니다.
