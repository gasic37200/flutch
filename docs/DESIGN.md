# FLUTCH Design System

> 상태: **v1 시안 검토 중**. 시안: [FLUTCH 디자인 시안 (아티팩트)](https://claude.ai/artifact/X4mcgYsXY9tngprQf1qh6N) — 보드 23장: 디자인 시스템 · 홈(데스크톱·모바일·SUPER CLUTCH 히어로) · 시청(데스크톱·모바일·상태 4종) · 송출 스튜디오(송출 전·방송 중 PC·모바일) · 로그인 · 회원가입 · 비로그인 상태 · 방송 등록·수정 · 스트리머 페이지(관리 탭) · 내 지갑·충전 · 다시보기 목록·상세 · 탐색 · PULSE · 오버레이 · 에러 3종 · **공통 컴포넌트(사용처 표시)** · **작은 화면**(내 정보·탈퇴·카카오 닉네임·결제 결과·약관·스튜디오 모달·차단 입력창). 비공개 링크라 사용자 계정으로만 열린다.
> 모든 화면이 시안에 있다. 새 화면이 필요하면 §9의 공통 컴포넌트를 조합한다.
> 코드에서는 아래 토큰을 `frontend/src/styles/tokens.css` + Tailwind 설정과 1:1로 맞춘다.
> 원본 시안: `docs/design-refs/*`. **화면에 쓰는 가공 에셋**(투명 배경·워터마크 제거·표정 잘라내기 완료): `docs/design-refs/brand/*`.

## 1. 무드
어두운 무대 위의 네온. 게임 방송의 속도감(사선, 스피드 라인)과 "심장이 뛰는 순간"(심박 라인, 게이지)을 표현한다.
배경 텍스처: **네온 스피드 라인 + 앵귤러 스트릭 + 하프톤 도트 + 그런지** (`brand/bg-speed.jpg`).

## 2. 색 토큰 (색마다 의미는 하나)
| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#0A0C0F` | 페이지 배경 |
| `surface` | `#12151B` | 패널, 카드 |
| `surface-2` | `#191D25` | 입력창, 일반 버튼, 칩, 안내 배너 |
| `border` | `#262B35` | 구분선, 비활성 막대 |
| `brand` | `#B0F612` (로고 심박 라인에서 추출) | 선택 상태, 주요 버튼, 게이지, 비트 아이콘, 강조 테두리 |
| `brand-line` | `rgba(176,246,18,.25)` | **기본 테두리**(은은한 네온) |
| `live` | `#FF2E4D` | **LIVE 배지·시청자 수·방송 종료 버튼만** |
| `clutch` | `#FF2BD6 → #FF7A1A → #FFE11A` 그라데이션 | **클러치 폭발만**: 게이지 MAX, COMBO, SUPER CLUTCH |
| `burst` | `#FFC21A` | **SUPER BURST 버튼, 1만 비트 이상 큰 후원 연출, 후원자 배지만** |
| `text` / `text-muted` / `text-dim` | `#F3F5F7` / `#A3AAB6` / `#7C8494` | 본문 / 보조 / 비활성·힌트 |
- 비트(화폐)는 **라임 파동(심박) 아이콘 + 흰색 숫자**. 헤더 잔액은 라임 테두리 알약.
- 경고·안내 배너는 `surface-2` 배경 + 흰 글자 + 라임 아이콘(골드·빨강 쓰지 않음).
- 레벨 미터: 정상 라임, 높음 흰색.
- 기본 프로필 링 색 6종: `#B0F612` `#2EE6D6` `#4DA3FF` `#9B7BFF` `#5CF2A0` `#E8ECF1` (빨강·골드·그라데이션 금지). 채팅 닉네임 색도 같은 팔레트.

## 2-1. 클러치 로고타입 3단계
게이지가 오를수록 라임(평소) → 뜨거운 그라데이션(폭발). "CLUTCH" 붓글씨 스타일은 세 로고 공통.
| 단계 | 파일 (`brand/`) | 색 | 쓰는 곳 |
|---|---|---|---|
| 충전 중 (0~79%) | `logo-clutch-time.png` | CLUTCH 흰색 + TIME 라임 | 히어로 CLUTCH TIME 패널 기본, 시청 화면 게이지 라벨 |
| 임박 (80~99%) | `logo-clutch-time-hot.png` | CLUTCH 그라데이션 + TIME 흰색 | 히어로 패널 임박(맥박 연출) |
| 발동 | `logo-super-clutch.png` | SUPER 그라데이션 + CLUTCH 흰색 | SUPER CLUTCH 3초 연출, 히어로 SUPER CLUTCH 카드 |
- 발동 연출 하단에 "Feel the Moment. Live on FLUTCH." 슬로건.
- AI 생성 이미지임을 README 출처에 표기한다.

## 4. 형태: 사선 모서리 (chamfer)
- **왼쪽 위 + 오른쪽 아래** 대각선 2곳을 깎는다. 큰 카드·패널 **12px**, 버튼·칩·입력창 **6px**, 배지(LIVE 등)는 깎지 않음.
- 테두리 3단계:
  | 상태 | 테두리 |
  |---|---|
  | 기본 | `brand-line` 1px (은은한 네온) |
  | 호버·선택 | `brand` 1px |
  | **메인 히어로**(홈 라이브 영상 + CLUTCH TIME 패널), 후원 알림 | `brand` 1px + 글로우 `drop-shadow(0 0 12px rgba(176,246,18,.4))` |
  | SUPER CLUTCH 카드 | `clutch` 그라데이션 1px |
- 구현: `clip-path`로 바깥 층(테두리색) + 1px 안쪽 층(배경). **글로우는 clip-path가 없는 바깥 래퍼에** 걸어야 잘리지 않는다. 공통 컴포넌트 `<Panel>`, `<Button>`, `<Chip>`만 이 모양을 만든다.
- 장식: 큰 패널(히어로, CLUTCH TIME, 배너) 모서리에만 **하프톤 도트 + 꺾인 네온 라인**.

## 5. 이미지 기본값
- 기본 프로필: **마스코트 표정 6종(`brand/face-*.png`) × 링 색 6종**, 사용자 id로 고정. 원형.
- 상황별 표정: 빈 화면 = `sleepy`, 에러 = `grumpy`, 결제·후원 완료 = `happy`/`joy`, SUPER CLUTCH = `excited`.
- 썸네일 없음: 배경 텍스처 + 카테고리 이름(Chakra Petch) + 작은 졸린 고양이.
- 빈 화면: 큰 마스코트 + "지금은 조용하네요. 첫 번째 클러치를 만들어 보세요" + 방송하기 버튼.
- 사이드바 하단 배너: `brand/banner-play-on-flutch.png`. 로그인 화면: `brand/mascot-controller.png`.

## 6. 움직임
- 애니메이션은 **게이지 차오름, 임박 맥박, COMBO 팝업, 후원 알림 등장, SUPER CLUTCH 연출**에만.
- 글로우는 강조 요소에만. `prefers-reduced-motion` 사용자에게는 끈다.

## 7. 레이아웃
- 홈(데스크톱): 헤더 / 왼쪽 사이드바(PULSE + 메뉴 + PLAY ON FLUTCH 배너) / 본문: **히어로(라이브 영상 + 오른쪽 CLUTCH TIME 패널)** → 추천 라이브 채널 3칸 → CLUTCH FEED → 지금 두근거리는 중!(카테고리 칩 + 그리드).
- 시청(데스크톱): 영상(웹캠 PIP, 하단 컨트롤) → **가로 클러치 게이지 바**(로고 라벨 · 게이지 · CLUTCH 버튼+COMBO · SUPER BURST) → 방송 정보(팔로우·후원하기) → 이 방송 후원 / 오른쪽 채팅 패널.
- 송출 스튜디오(PC): 상단 LIVE·시간·시청자·녹화·방송 종료 / 미리보기 + 영상 카드(모드·화면 바꾸기·웹캠 PIP·위치) + 소리 카드(볼륨 슬라이더·레벨 미터) / 오른쪽: 방송 정보 수정, 후원 알림 대기열(스킵), 채팅.
- 모바일: 1열. 시청은 영상 → 게이지 바 → 정보 → 채팅/후원 탭 → 입력. 스튜디오는 전체 화면 카메라 위에 컨트롤 오버레이.
- 좁아지면 사이드바·오른쪽 패널이 아래로 쌓인다(flex-wrap). 다크 모드 고정, 한국어만.

## 7-1. 헤더
- 로그인: `로고 | 검색 | [비트 잔액 알약] [방송하기 아이콘] [아바타 메뉴]`. 알림 종 없음.
- 비로그인: `로고 | 검색 | [방송하기 아이콘] [로그인 버튼]`. 방송하기는 로그인 후 스튜디오로 복귀.
- 방송하기 아이콘: 작은 카메라 아이콘, hover 시 "방송하기". 사이드바 하단 배너와 같은 목적지.
- 아바타 메뉴: 내 채널 · 내 지갑 · 내 정보 · 로그아웃.
- 모바일: 햄버거 | 로고 | 검색 아이콘 | 방송하기 아이콘 | 아바타(또는 로그인). 잔액은 아바타 메뉴 안.

## 8. 금지
- hex 값 직접 사용 (토큰만)
- `live`·`burst`·`clutch` 색을 다른 의미로 사용, 비트 금액에 파동 아이콘 빼기
- 기본 상태 카드에 밝은 네온 테두리(밝은 네온은 호버·선택·메인 히어로만)
- "준비 중" 메뉴 노출, 이모지 아이콘

## 9. 공통 컴포넌트와 사용처
`frontend/src/components/ui/`에 한 번만 만들고 아래 화면에서 재사용한다. 시안: "공통 컴포넌트" 보드.
| 컴포넌트 | 사용처 |
|---|---|
| `Modal` (제목·닫기·본문·버튼, ESC·배경 클릭 닫기, 첫 입력 포커스) | 후원 창, 충전 창, 탈퇴, 방송 이어하기, 기기 전환, 삭제 확인 |
| `ConfirmDialog` (위험 동작) | 방송 종료(빨강 버튼), 방송 삭제·영구 밴·탈퇴(흰 테두리 버튼 + 경고 문구) |
| `Toast` (성공=라임 / 안내·에러=흰색, 4초, 에러는 닫을 때까지, request_id 표시) | 저장, 후원 완료, 채팅 제한·도배 거절, 요청 실패, 네트워크 |
| `Dropdown` | 헤더 아바타 메뉴(내 채널·내 지갑·내 정보·로그아웃), 방송 관리 ⋯, 정렬·카테고리 |
| `Field` (기본·포커스·에러·비활성, 글자 수) | 가입·로그인, 방송 등록, 채팅, 후원 메시지, 충전 금액, 내 정보 |
| `Button` (기본·호버·비활성·로딩) | 전역. 로딩 중에는 중복 클릭 막기 |
| `Tabs` / `Switch` / `ChoiceChip` | 스트리머 페이지 탭, 모바일 채팅/후원 탭, 녹화·웹캠 스위치, 금액 프리셋, 카테고리 |
| `Skeleton` | 홈·탐색·PULSE·다시보기 목록, 채팅 이전 기록, 지갑 내역 |
| `EmptyState` (마스코트 + 제목 + 설명 + 다음 행동) | 라이브 없음, 검색 결과 없음, PULSE 0개, 내역 없음, 다시보기 없음, 차단 목록 없음 |
| `Badge` | LIVE, READY, ENDED, SUPER CLUTCH, 스트리머, 후원자, 익명, (수정됨), 녹화 상태 |
| `Tooltip` | 아이콘 버튼, 다시보기 SUPER CLUTCH 지점, 비활성 버튼 이유 |
| `Panel` / `Avatar` / `BeatAmount` / `ClutchGauge` / `LiveCard` | 모든 카드·패널, 프로필, 비트 금액(파동 아이콘), 게이지 3단계, 라이브·다시보기 카드 |
- 에러 문구는 빨강을 쓰지 않는다(흰 글자 + 아이콘). 빨강 버튼은 "방송 종료"에만.
