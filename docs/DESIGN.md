# FLUTCH Design System

> 상태: **초안**. 토큰 값은 기반 단계에서 시안(`docs/design-refs/`)에서 추출해 확정하고, `frontend/` Tailwind 설정과 1:1로 맞춘다.
> 시안 참고: `home.webp`(홈), `super-clutch-card.png`(클러치 카드), `chamfer-corner.png`(모서리), `mascot-play-on-flutch.png`(마스코트), `background.webp`(배경), `logo-flutch.png`(로고), `logo-clutch-time.png`(CLUTCH TIME 로고타입), `mascot-concept-sheet.webp`(마스코트 표정·소품).

## 1. 무드
어두운 무대 위의 네온. 게임 방송의 속도감(사선, 스피드 라인)과 "심장이 뛰는 순간"(심박 라인, 게이지)을 표현한다.
배경 텍스처: **네온 스피드 라인 + 앵귤러 스트릭 + 하프톤 도트 + 그런지**.

## 2. 색 역할 (색마다 의미는 하나)
| 토큰 | 용도 | 비고 |
|---|---|---|
| `bg` | 페이지 배경 | 거의 검정 (#0B0D10 계열) |
| `surface` / `surface-2` | 패널, 카드 / 한 단계 위 | 남색빛 회색 |
| `border` | 기본 테두리 | 어두운 회색 1px |
| `brand` | 네온 라임: 선택 상태, 주요 버튼, 게이지, 강조 테두리 | 시안 라임 |
| `live` | 빨강: **LIVE 배지·시청자 수만** | |
| `clutch` | 핑크 → 주황 → 노랑 그라데이션: **Clutch 관련만** (콤보, SUPER CLUTCH, 게이지 MAX) | |
| `beat` | 비트(화폐) 표시: **라임 파동(심박) 아이콘 + 흰색 숫자**, 라임 테두리 알약(헤더 잔액·후원 금액·지갑) | 비트 = 심박. 아이콘은 항상 파동 |
| `burst` | 골드: **SUPER BURST 버튼과 1만 비트 이상 큰 후원 연출에만** | 시안 SUPER BURST 버튼 색 |
| `text` / `text-muted` / `text-dim` | 본문 / 보조 / 비활성 | |

## 2-1. 클러치 로고타입 3단계
게이지가 오를수록 라임(평소) → 뜨거운 그라데이션(폭발)으로 넘어가는 흐름을 로고로 보여준다. "CLUTCH" 단어의 붓글씨 스타일은 세 로고 공통.
| 단계 | 파일 | 색 | 쓰는 곳 |
|---|---|---|---|
| 충전 중 (0~79%) | `logo-clutch-time.png` | CLUTCH 흰색 + TIME 라임 | 히어로 CLUTCH TIME 패널 기본, 시청 화면 게이지 라벨 |
| 임박 (80~99%) | `logo-clutch-time-hot.webp` | CLUTCH 그라데이션 + TIME 흰색 | 히어로 패널 임박 상태 |
| 발동 | `logo-super-clutch.webp` | SUPER 그라데이션 + CLUTCH 흰색 | SUPER CLUTCH 3초 연출, 히어로 SUPER CLUTCH 카드 |
- 원본 오른쪽 아래의 생성 도구 워터마크(✦)는 잘라내고 쓴다. 검은 배경은 투명 처리하거나 `mix-blend-mode: screen`으로 합성한다.
- AI 생성 이미지임을 README 출처에 표기한다.

## 4. 형태: 사선 모서리 (chamfer)
- **왼쪽 위 + 오른쪽 아래** 대각선 2곳을 깎는다.
- 크기: 큰 카드·패널 **12px**, 버튼·칩 **6px**, 배지(LIVE 등)는 깎지 않음.
- 테두리: 평소 `border` 1px → **선택·호버·라이브 강조 시 `brand` 네온 + 약한 글로우**.
- 구현: `clip-path` 다각형으로 바깥 층(테두리색)과 1px 안쪽 층(배경)을 겹친다. 공통 컴포넌트 `<Panel>`, `<Button>`, `<Chip>`만 이 모양을 만든다.
- 장식: 큰 패널(히어로, CLUTCH TIME, 배너) 모서리에만 **하프톤 도트 + 꺾인 네온 라인**.

## 5. 이미지 기본값
- 기본 프로필: **마스코트 고양이 얼굴 + 배경색 6종**, 사용자 id로 고정.
- 썸네일 없음: 배경 텍스처를 어둡게 + 카테고리 이름 + 작은 고양이 아이콘.
- 빈 화면: 큰 마스코트 + "지금은 조용하네요. 첫 번째 클러치를 만들어 보세요" + 방송 시작 버튼.

## 6. 움직임
- 애니메이션은 **게이지 차오름, 콤보 팝업, SUPER CLUTCH 연출**에만.
- 글로우는 강조 요소에만, 약하게.
- `prefers-reduced-motion` 사용자에게는 끈다.

## 7. 레이아웃
- 데스크톱: 왼쪽 사이드바(PULSE + 메뉴 + PLAY ON FLUTCH 배너) / 본문 / 오른쪽 패널(CLUTCH TIME + 추천 라이브).
- 좁아지면 오른쪽 패널 → 사이드바 순으로 접힘. 모바일 시청 화면은 영상 아래 채팅.
- 다크 모드 고정, 한국어만.

## 7-1. 헤더
- 로그인: `로고 | 검색 | [비트 잔액 알약] [방송하기 아이콘] [아바타 메뉴]`. 알림 종 없음.
- 비로그인: `로고 | 검색 | [방송하기 아이콘] [로그인 버튼]`. 방송하기는 로그인 후 스튜디오로 복귀.
- 방송하기 아이콘: 작은 카메라 아이콘, hover 시 "방송하기". 사이드바 하단 PLAY ON FLUTCH 배너와 같은 목적지(배너는 넓은 화면 홍보용, 아이콘은 모든 화면·모바일 기본 입구).
- 아바타 메뉴: 내 채널 · 내 지갑 · 내 정보 · 로그아웃.
- 모바일: 로고 | 검색 아이콘 | 방송하기 아이콘 | 아바타(또는 로그인). 잔액은 아바타 메뉴 안. 사이드바는 햄버거 메뉴.

## 8. 금지
- hex 값 직접 사용 (토큰만)
- `live`·`burst`·`clutch` 색을 다른 의미로 사용, 비트 금액에 파동 아이콘 빼기
- 모든 카드를 네온으로 빛나게 하기
- "준비 중" 메뉴 노출
